# Profice Feedback Analyzer

AI-powered training-feedback analytics for colleges. Upload student feedback and the
platform classifies sentiment, extracts topics, and generates grounded insights,
summaries and recommendations — all behind role-based access control.

> Sentiment and keywords are derived by an LLM reading the **actual feedback text**
> (not just the star rating), and every number on the dashboards is exact math on the
> database. Qualitative AI output is generated by **Google Gemini**; quantitative output
> is deterministic aggregation.

---

## Features

- **AI feedback analysis (RAG over your data)** — on upload, feedback text is classified
  into positive / neutral / negative and tagged with topic keywords by Google Gemini
  (batched, deterministic). Falls back to rating-based logic if the AI is unavailable.
- **AI insights** — executive dashboard summary, per-file analysis, trainer
  strengths / weaknesses / recommendations, course improvement suggestions, and an
  AI recommendation engine (suggestions, risks, performance prediction).
- **Role-Based Access Control** — five roles (`super_admin`, `management`,
  `program_manager`, `trainer`, `ace_lead`) with capability-gated pages and API routes.
  Trainers are data-scoped to their own feedback only.
- **Dashboards & reporting** — sentiment distribution, top appreciated / improvement
  topics, trainer / course / batch insights, an action tracker, and filterable reports
  with PDF / Excel / CSV export.
- **Spreadsheet import** — bulk-import `.xlsx` / `.csv`; columns are auto-detected
  (student, college, course, trainer, rating, feedback text, …).

## How the AI works

```
Upload (.xlsx/.csv)
      │
      ▼
Parse rows ──► Gemini batch classify (sentiment + keywords, from TEXT) ──► store in MySQL
      │                       (fallback: rating/column + regex if AI off)
      ▼
Dashboards & insights ──► deterministic aggregation (counts, %, averages, rankings)
      │
      ▼
Narrative AI ──► Gemini generates summaries / recommendations grounded in the rows
```

- **Classification** runs at `temperature: 0` → the same feedback always gets the same
  label (reproducible), stored once per record.
- **Narrative** outputs (summaries, recommendations) are naturally worded and cached
  briefly; the numbers they sit beside are always exact DB math.

## Getting Started

### Prerequisites
- Node.js 18+ and npm
- A MySQL 8 instance
- A Google Gemini API key ([aistudio.google.com/apikey](https://aistudio.google.com/apikey))

### 1. Database

Point `DATABASE_URL` at your MySQL instance. For a quick local one via Docker:

```bash
docker run -d --name profice-mysql -p 3306:3306 \
  -e MYSQL_ALLOW_EMPTY_PASSWORD=yes -e MYSQL_DATABASE=profice_feedback mysql:8
```

### 2. Backend

```bash
cd backend
cp .env.example .env          # then edit values (see below)
npm install
npx prisma generate
npx prisma db push            # create schema (or: npx prisma migrate dev)
npm run prisma:seed           # seed colleges/courses/trainers/users/sample feedback
npm run dev                   # http://localhost:5000
```

`backend/.env`:

```env
PORT=5000
DATABASE_URL="mysql://root@localhost:3306/profice_feedback"
JWT_SECRET="change-me"
JWT_EXPIRES_IN="7d"
GEMINI_API_KEY="your_gemini_api_key"
GEMINI_MODEL="gemini-flash-lite-latest"
```

> Without `GEMINI_API_KEY`, the app still runs — AI features fall back to deterministic
> rating/keyword logic.

### 3. Frontend

```bash
cd feedback-analyzer
npm install
npm run dev                   # http://localhost:5173 (proxies /api → :5000)
```

Open **http://localhost:5173** and sign in.

## API Overview

Base URL: `/api/v1`

| Area | Endpoints |
|------|-----------|
| Auth | `POST /auth/login`, `GET /auth/me` |
| Dashboard | `/dashboard/{stats,trends,sentiment,topics,recent}` |
| Feedback | `/feedback`, `/feedback/stats`, `/feedback/export`, … |
| Trainers / Courses / Batches | `/trainers/:id/metrics`, `/courses/:id/metrics`, `/batches` |
| Actions | `/actions` (CRUD) |
| Reports | `/reports/data`, `/reports/export/{pdf,excel,csv}` |
| Upload | `/upload/analyze`, `/upload/sessions/:id/analysis` |
| AI | `/ai/dashboard-summary`, `/ai/recommendations` |

All non-auth routes require a Bearer JWT and are gated by role capability.

## Security Notes

- Secrets live only in `backend/.env` (git-ignored) — never commit them.
- Passwords are bcrypt-hashed; tokens are JWTs signed with `JWT_SECRET`.
- Set a strong `JWT_SECRET` in production (the app refuses to start in `production`
  without one).
- The AI chat/free-form endpoint executes no LLM-authored SQL — retrieval uses
  parameterized Prisma queries only.
